================================================================================
                    LIVELENS - PROJECT TECH STACK & ARCHITECTURE
================================================================================

1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
LiveLens is a real-time, low-latency web application designed to turn any smartphone 
into a wireless document camera or live video feed for projectors and external displays 
over Wi-Fi / Internet without requiring native mobile app installations.


2. CORE STREAMING & REAL-TIME NETWORKING
--------------------------------------------------------------------------------
* WebRTC (Web Real-Time Communication):
  - Component: RTCPeerConnection, RTCSessionDescription, RTCIceCandidate
  - Purpose: Ultra-low latency, peer-to-peer (P2P) direct audio/video streaming 
    from phone camera directly to projector display.
  - Video data travels directly device-to-device with sub-frame latency.

* Cloudflare Workers & Durable Objects (Native Edge WebSocket Signaling):
  - Purpose: Real-time edge bidirectional signaling channel (/ws/:roomCode).
  - Built with Hono and Cloudflare Durable Objects (SignalingRoom).
  - Exchanging WebRTC session descriptions (SDP Offer / Answer) and ICE candidates.
  - Room management based on 6-digit session pairing codes.
  - Instant edge synchronization of camera commands (Zoom, Rotation, Mirroring, Torch).

* STUN Servers:
  - Google STUN (stun:stun.l.google.com:19302, stun:stun1.l.google.com:19302)
  - Twilio STUN (stun:global.stun.twilio.com:3478)
  - Purpose: NAT traversal and discovering candidates for direct P2P link.


3. SINGLE UNIFIED ROOT ARCHITECTURE (CLOUDFLARE WORKERS)
--------------------------------------------------------------------------------
* Root Configuration:
  - package.json: Single root package with zero split backend/frontend overhead.
  - wrangler.jsonc: Cloudflare Worker, Durable Object bindings, and static assets.
  - vite.config.ts: Vite 6 + @cloudflare/vite-plugin + @vitejs/plugin-react.

* Edge Backend:
  - Cloudflare Workers runtime
  - Hono v4: Lightweight edge routing
  - Durable Objects: Distributed stateful WebSocket signaling room

* Frontend UI & Components:
  - React 19 + TypeScript
  - Tailwind CSS + PostCSS + Autoprefixer
  - Lucide React (camera icons, HUD controls)
  - qrcode.react: On-screen pairing QR code generation
  - Components:
    * Broadcaster: Phone camera capture, controls, and WebRTC streaming
    * Viewer: Projector display, QR pairing screen, fullscreen video presentation
    * Controls: Modern mobile thumb deck, zoom dial, rotation, mirror, torch

4. DEPLOYMENT & COMMANDS
--------------------------------------------------------------------------------
* Development:
  - npm run dev: Starts unified Vite + Cloudflare local dev environment.
* Production Build:
  - npm run build: Bundles React SPA client and Worker SSR edge bundle.
* Edge Deployment:
  - npm run deploy: Builds and deploys directly to Cloudflare global network via Wrangler.
