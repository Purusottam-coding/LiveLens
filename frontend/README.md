# LiveLens - Frontend 📱📽️

Frontend client for LiveLens: turns smartphones into wireless HD cameras that stream in real-time to a projector screen via WebRTC.

## 🚀 Features
- **Phone Camera Broadcasting:** Low-latency WebRTC streaming with front/rear camera switching & torch control
- **Projector Viewer:** Fullscreen canvas viewer with pairing code display
- **Pairing System:** Instant connection via 6-digit session codes

## 🛠️ Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** CSS3 / PostCSS
- **Communication:** Socket.io client & WebRTC

## 📦 Setup & Development
```bash
# Install dependencies
npm install

# Copy environment template
cp .env.example .env

# Run development server
npm run dev
```
